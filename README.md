# Проектный менеджмент: командная практика

Репозиторий команды для практической работы по дисциплине «Проектный менеджмент». В нём собраны результаты пяти взаимосвязанных фаз: выбор концепции, распределение работ, оценка масштаба, прогнозирование сроков и календарное планирование. ## Фаза 1: выбор концепции

### Задача фазы

Команда подготовила набор альтернатив программного проекта, описала критерии выбора, выполнила индивидуальное экспертное оценивание и сравнила результаты двух методов принятия решений.

### Подход

- сформированы не менее четырёх вариантов концепции;
- определены критерии и трёхточечные оценки `(L; M; U)`;
- применён нечёткий коллективный TOPSIS;
- выполнен расчёт коллективного МАИ и проверка согласованности матриц;
- результаты методов сопоставлены и обсуждены командой.

По итогам сравнения методов TOPSIS и МАИ основной концепцией выбрана **RepairDesk**. Отчёт и расчётная книга доступны в [материалах первой фазы](phase-01/README.md).

## Принципы ведения проекта

Каждая фаза разбивается на наблюдаемые задачи. Для задачи в YouGile указываются исполнитель, участники, период, оценка трудозатрат, ожидаемый результат и фактический статус. После завершения фазы уточняется матрица ответственности и сохраняются расчётные материалы.
