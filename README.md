# Командный проект по управлению проектами

Рабочее пространство команды для сквозного задания по дисциплине «Управление проектами». Здесь будут собраны расчёты, исходные данные, код и выводы по всем пяти фазам, а также материалы для итогового отчёта.

## Навигация по репозиторию

| Каталог | Раздел задания | Что хранить |
| --- | --- | --- |
| `phase-01-concept/` | Выбор концепции | Альтернативы, критерии, экспертные оценки, TOPSIS, МАИ и итоговый выбор. |
| `phase-02-allocation/` | Распределение работы | Декомпозиция оценки проекта, оценки трудоёмкости и предпочтений, модель назначений и решение. |
| `phase-03-estimation/` | Оценка проекта | Use Cases, COSMIC FP, Use Case Points, экспертная оценка масштаба. |
| `phase-04-forecast/` | Прогнозирование | Трёхточечные оценки и результаты двух моделей Монте-Карло. |
| `phase-05-planning/` | Планирование | Работы, ресурсы, зависимости, эвристики и календарный план. |
| `final-materials/` | Итоговый отчёт | Сводный отчёт, актуальная RACI-матрица и ссылка на трекер задач. |

## Правила ведения

- Для каждой фазы декомпозируем работу на отдельные задачи и назначаем исполнителя.
- Актуализируем RACI-матрицу после завершения каждой фазы.
- Указываем период выполнения и фактическое чистое время работы по задачам в выбранном трекере.
- Сохраняем расчётные таблицы, исходный код и краткие выводы вместе с материалами соответствующей фазы.
