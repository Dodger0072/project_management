# Фаза 1: выбор концепции

**Статус: завершена.** Команда сравнила шесть вариантов программного проекта и выбрала для дальнейших фаз систему заявок на ремонт оборудования **RepairDesk**.

## Выполненные работы

- сформировано шесть альтернативных концепций;
- определено семь критериев выбора;
- все четыре участника дали индивидуальные трёхточечные экспертные оценки;
- выполнен расчёт нечёткого коллективного TOPSIS;
- выполнен расчёт чёткого коллективного МАИ и проверена согласованность матриц;
- сопоставлены результаты методов и сформулирован итоговый вывод.

## Итоги выбора

| Метод | Лидер | Результат |
| --- | --- | ---: |
| Нечёткий коллективный TOPSIS | RepairDesk | `CC = 0,8836` |
| Коллективный МАИ | BudgetMate | `0,2401` |

RepairDesk занял второе место в МАИ (`0,2267`) и первое в TOPSIS. Учитывая устойчиво высокий результат в обоих методах, понятную предметную область и пригодность для последующих фаз, команда приняла RepairDesk как основную концепцию проекта. Все проверенные матрицы МАИ удовлетворяют условию согласованности `CR <= 0,10`.
