# 01 Выбор концепции

Материалы первой фазы: выбор концепции программного проекта.

## Результаты фазы

- не менее четырёх альтернативных концепций;
- не менее четырёх критериев и их веса;
- индивидуальные трёхточечные экспертные оценки;
- расчёт нечёткого коллективного TOPSIS;
- расчёт чёткого коллективного МАИ;
- сопоставление результатов и обоснованный выбор темы.

## Рекомендуемые файлы

- `alternatives-and-criteria.xlsx` — альтернативы, критерии и оценки;
- `topsis-mai-calculations.ipynb` — воспроизводимые расчёты;
- `decision-summary.md` — вывод и выбранная концепция.
