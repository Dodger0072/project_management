# 05 План ресурсов и сроков

Материалы пятой фазы: календарное планирование разработки проекта.

## Результаты фазы

- 20–25 задач реализации;
- состав команды по специализациям;
- ресурсные требования и связи предшествования;
- несколько эвристик упорядочения работ и итоговое решение;
- календарный план в восьмичасовом рабочем графике.

## Рекомендуемые файлы

- `implementation-tasks.xlsx` — задачи, длительности, ресурсы и зависимости;
- `scheduling-heuristics.py` — реализация эвристик;
- `calendar-plan.md` — обоснование итогового графика.
