# 02 Распределение работы

Материалы второй фазы: назначение работ из фазы оценки проекта между участниками команды.

## Результаты фазы

- декомпозиция работ фазы 3;
- экспертные оценки трудоёмкости задач;
- предпочтения каждого участника;
- формальная постановка задачи о назначениях с целевой функцией и ограничениями;
- решение модели и интерпретация распределения.

## Рекомендуемые файлы

- `work-breakdown.md` — список и описание задач;
- `effort-and-preferences.xlsx` — входные оценки;
- `assignment-model.py` — код модели;
- `allocation-result.md` — итоговое распределение.
