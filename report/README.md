# Итоговые материалы

В этот каталог войдут финальные документы, объединяющие все пять фаз.

## Обязательное содержание

- итоговый отчёт с результатами и промежуточными артефактами фаз;
- актуальная матрица RACI;
- обоснование распределения задач;
- ссылка на публичный таск-трекер с исполнителями, сроками, оценками и учётом времени.

## Файлы

- `final-report.docx` — итоговый отчёт;
- `raci-matrix.xlsx` — актуальная матрица ответственности;
- `tracker-link.md` — ссылка и краткое описание организации задач.
