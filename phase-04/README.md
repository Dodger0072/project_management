# 04 Прогнозирование сроков

Материалы четвёртой фазы: вероятностный прогноз выполнения работ из фазы планирования.

## Результаты фазы

- трёхточечные оценки продолжительности задач;
- модель Монте-Карло с выбором исполнителей случайным образом;
- модель Монте-Карло с распределением задач по предпочтениям;
- оценка срока завершения с вероятностью 80 %;
- сравнение моделей и объяснение различий.

## Рекомендуемые файлы

- `three-point-estimates.xlsx` — оптимистичные, ожидаемые и пессимистичные оценки;
- `monte-carlo-simulation.py` — код экспериментов;
- `forecast-results.md` — графики, квантили и выводы.
