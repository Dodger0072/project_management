# 03 Оценка масштаба

Материалы третьей фазы: оценка выбранного программного проекта и трудозатрат.

## Результаты фазы

- не менее десяти Use Cases;
- оценка в COSMIC Function Points;
- оценка в Use Case Points и расчёт трудозатрат;
- коллективная экспертная оценка;
- оценка трудозатрат по Use Cases или пользовательским историям;
- сопоставление подходов и вывод о масштабе проекта.

## Рекомендуемые файлы

- `use-cases.md` — сценарии и акторы;
- `cosmic-ucp.xlsx` — расчётные таблицы;
- `estimation-notes.md` — допущения и выводы.
